# Audio Analyzer

STM32F303RE audio analyzer project for STM32CubeIDE.

## Build

1. Install STM32CubeIDE with the STM32F3 toolchain.
2. Select File > Import > Existing Projects into Workspace and select this folder.
3. Build the Debug or Release configuration.

The required CMSIS-DSP headers and Cortex-M4 floating-point library are included in Drivers/CMSIS.
